### Hazards and lessons recorded here (not written elsewhere)

- `dart run build_runner build --build-filter` deleted about 40 unrelated generated files in one round. Use a full build and compare md5 of all generated files.
- `dartDeclaresField` (`test/guards/rules.dart`) matches `\bfield\s*[,)}]` anywhere in a class body, so a `toString` that interpolates `$field,` satisfies a required-field binding with the real constructor parameter deleted (reproduced twice, by W3b and W3d; BUG-052). `contractRequiredFields` cannot reach inline schemas; `test/dev/contract_inline.dart` is a working reference.
- `Semantics(selected:)` on a row already isolates it, so `MergeSemantics` there is redundant (the mutation survives); what made rows `ImageView`s was the avatar's default image semantics. A podium `Column` with no `Semantics` ancestor does need `MergeSemantics` per place.
- Riverpod 3.3.2 flushes an invalidated provider only if it is active: a paused listener (a hidden tab) is not rebuilt by `ref.invalidate`. A test that triggers a forced sign-out must invalidate the provider the student is on.
- A widget test that pumps two apps in one test and holds an autoDispose provider can leave a zero-length disposal `Timer` pending; unmount the first tree first.
- Nested `PopScope`s each fire their handler: do not wrap `RegistrationExpiredView` in a second one.
- `LoginNotifier.build` is `async => null`, so `loginProvider` is `AsyncLoading` for one microtask and the new `isLoading` guard also ignores a `sendOtp` issued in that window; a future direct caller must await `loginProvider.future` first.
- `AuthRepository.verifyOtp` sends `device.toJson()` unchanged, so a null `DeviceInfo.model` goes out as `"model": null` while `confirmRecovery` omits it; `deviceInfoProvider` always supplies a model today (latent, W3c).

Models deliberately left unredacted that still print reference or catalogue rows: `ProfileGeography`, `ProfileSchool`, `ProfileUniversity`, registration's preset `Avatar`, `FavoriteQuestion`, `QuizQuestion`, `QuizOption`. If the contract ever lets a student type free text into any of them, add its name to the census matcher. `ProfileAvatar.url` is personal only on `ProfileAvatar`.
